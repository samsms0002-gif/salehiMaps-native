# صيغة AQB

AQB هو ملف ثنائي مضغوط يصف مصادر الخرائط والمستويات والفهارس. تم استخراج البنية من الصنف `aqp2/avt`.

## الترويسة

أول 4 بايتات هي magic number يُقرأ عبر `bkg.e(inputStream)` ويُقارن بـ `avr.a`. أي قيمة مختلفة تؤدي إلى:

`Invalid AQB magic number!`

## هيكل المستوى الأعلى

بعد الـ magic تُقرأ كتلة بيانات:

```text
magic (4)
[compressed block length][compressed block data]
```

تُفك الكتلة إلى قاموس `bdd` يحتوي مفاتيح مثل:

| المفتاح | المعنى |
|---|---|
| `i` | معرّف المجموعة/المصدر |
| `n` | الاسم |
| `d` | الوصف |
| `©` | حقوق النسخ |
| `a` | المنطقة |
| `v` | الإصدار |
| `r` | المراجعة |
| `p` | معاملات |
| `u` | طابع زمني |

## المصادر

داخل الكتلة توجد قائمة مصادر، لكل مصدر:

| المفتاح | المعنى |
|---|---|
| `i` | معرّف المصدر (إلزامي؛ وإلا `AQB source ID cannot be null!`) |
| `n`, `d`, `s`, `c` | الاسم، الوصف، الرابط، حقوق النسخ |
| `w` | بيانات حدود المنطقة |
| `t`, `r`, `u`, `x` | النوع، المنطقة، الطوابع الزمنية |
| `j` | إعداد العرض |
| `m` | خريطة/حدود إضافية |
| `o` | الشفافية (الافتراضي 255) |
| `b` | نمط الخلط (الافتراضي 0) |
| `v`, `k`, `z` | قيم العرض/الزوم |
| `y`, `h`, `p` | علم flags: layer / hd / deprecated |
| `l` | قائمة مستويات الزوم |

## مستوى الزوم

كل مستوى يحتوي:

| المفتاح | المعنى |
|---|---|
| `z` | معرّف الزوم (إلزامي؛ وإلا `AQB level zoom ID missing!`) |
| `s` | قائمة المقاييس/الأحجام |
| `p` | بيانات الفهرس المضغوطة |
| `u` | نوع ترميز الإزاحة (`1`..`4`, `10`..`13`) |
| `w` | معاملات الترميز الإضافية |
| `t` | حجم البلاطة (الافتراضي 256) |
| `n` | عدد المستويات الفرعية (الافتراضي 3) |
| `d` | طابع زمني |
| `k` | مفتاح التخزين |
| `b` | مصفوفة من 16 بايت تحتوي 4 أرقام uint32 للحدود |

أنواع الترميز:

| القيمة | الاسم داخلياً |
|---:|---|
| 1 | abse encoder افتراضي |
| 2 | awp |
| 3 | awk |
| 4 | awj |
| 10 | awl |
| 11 | awn |
| 12 | awm |
| 13 | awo |

## العلاقة مع DAT

الملف النموذجي في بيانات المستخدم:

```text
CNT.UIPUEJO6.AQB
CNT.UIPUEJO6.AQB.K9QE0XA3.DAT
CNT.UIPUEJO6.AQB.K9QE0XA3.IDX
CNT.UIPUEJO6.AQB.ZGY765W6.PREVIEW
```

- `.AQB` يصف المصدر والمستويات.
- `.DAT` يحمل بيانات البلاطات بنفس بنية DAT الموصوفة سابقاً.
- `.IDX` فهرس إضافي.
- `.PREVIEW` صورة معاينة.

يجب ربط `.DAT` و`.IDX` بملف `.AQB` عبر بادئة الاسم، وليس عبر تخمين أصغر ملف.
